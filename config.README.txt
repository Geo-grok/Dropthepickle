AFFILIATE_TAG / AMAZON_ASSOCIATES_TAG: Amazon tag (e.g. yourid-20). BRAND_AFFILIATE_PARAMS: query string per brand domain, e.g. 'ref=abc123'. SIGNUP_ENDPOINT: form POST URL. The site posts to /api/signup on the Worker.
OWN_CODES: DropThePickle's own brand-issued discount codes (list of {brand, code, discount, conditions, shop_url, network, commission, approved, active, ends?}). Rendered as an "Our own code" callout with a copy button on /discount-codes, /discount-codes/<brand>, /deals, that brand's paddle pages and quiz results, with a commission disclosure. Lives here (not data/discount-codes.json) because scripts/refresh-codes rewrites that file daily. Set active:false or ends:YYYY-MM-DD to retire one.
